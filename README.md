# Collision Kings BX landing page

Upload `index.html`, `CNAME`, and the `assets` folder to your GitHub repository. In Settings > Pages, deploy from `main` branch root.

## Before publishing
1. Replace `REPLACE_WITH_SHOP_EMAIL` in index.html with the shop email. Current form opens the visitor's email app; it is not an automated submission system.
2. Add real images `assets/shop-front.jpg` and `assets/shop-interior.jpg`.
3. Confirm business phone, street address, Google Business Profile link and operating hours; add them to the page.
4. For automated submissions and damage-photo uploads, integrate a secure form provider such as Formspree, Jotform or a hosted form service. Do not put private API keys in this public repository.
5. Set GitHub Pages custom domain to collisionkingsbx.com and configure DNS at your domain registrar per GitHub documentation. Verify domain ownership and enable HTTPS.
